> **These are placeholders, not your stock.** Replace every file in this folder with a real photo of the item you sell before launch.

## Why they are here

No product photography exists in this project yet, so the storefront uses sample photos
from **Unsplash**, downloaded locally and converted to WebP. Unsplash photos are free to
use commercially under the [Unsplash License](https://unsplash.com/license) (no attribution
required, no resale of unmodified photos as stock). They are still **not photos of your
actual garments**, so descriptions, colours and fit can differ from what ships.

## How to replace them

1. Shoot each garment on a plain background or on a model, in portrait orientation.
2. Export to **900 × 1200** (3:4), WebP, quality ~80.
3. Keep the same file names and drop them into this folder — no code changes needed.
4. If you use different file names, update the `image` and `imageAlt` fields in
   `js/script.js` for the matching product.
5. Delete this note once every image is your own.

Keep the `imageAlt` text accurate: it is used by screen readers.
